# 슬라이드별 발표 멘트와 화면 진행

**SKALA 광주 2반 · G066 · 정준용 / 9장·300초**

기술 로고를 사용해 직접 그린 시스템 구성도 한 장에서 전체 구조, 백엔드, 프론트엔드, AI, 평가 영역 순서로 확대한다. 코드 발췌 없이 그림과 실제 저장 화면으로 설명한다.

[슬라이드별 최신 대본·화면 진행·예상 질문](../PRESENTATION_5MIN.md)을 기준으로 발표한다. 같은 멘트를 PPT 발표자 노트에도 넣었다.
