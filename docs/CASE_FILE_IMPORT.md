# 사건 파일 불러오기

사건 기록 → **사건 파일 불러오기** → 파일 선택 → 주장·자료 미리보기 → **파일 초안을 입력에 적용** → 가상 자료 여부 확인 → **가상 사건 저장** 순서로 사용한다. 저장된 사건에서 ‘사건에 질문하기’를 이용한다.

지원 형식은 UTF-8 **TXT·MD·JSON**, 파일 크기는 최대 256KiB다. TXT·MD는 문서 전체를 자료 원문으로 읽고 파일명과 기본 검토 질문을 채운다. Markdown을 HTML로 실행하지 않는다. 긴 원문은 자료당 8,000자 이내로 나누며 전체 24,000자/자료24개/주장8개·주장당700자와 기존 서버의 요청64KiB 한도를 적용한다. 한도를 넘은 내용은 조용히 버리지 않고 오류로 표시한다.

TXT·MD 내용은 기본적으로 처음부터 공개할 자료로 채워진다. 자료별 공개 시점을 나누려면 적용 후 원문을 구분하고 ‘처음부터 공개’를 조정하거나 JSON을 사용한다. JSON 예시는 `frontend/public/assets/recase-case-template.json`이며 명시적인 `synthetic_only: true`와 `recase_case_file_v1` 형식을 요구한다. `initially_released: false` 자료는 저장 후 기존 공개 절차를 따르며 공개 전 모델 입력에 들어가지 않는다. 기존 `data/practice/v1/cases.json` 연습 묶음은 12개 중 하나를 선택할 수 있다. 나중에 공개할 자료는 원래 공개 순서대로 정렬한 뒤 하나씩 공개한다.

선택·미리보기는 브라우저의 로컬 초안 처리다. 원본 파일/경로를 서버에 첨부하거나 파일을 선택하자마자 저장·분석하지 않는다. ‘적용’ 전 현재 입력을 바꾸지 않고, 적용 후에는 ‘이전 입력 복원’으로 한 단계 되돌릴 수 있다. 새 파일을 적용하면 가상 자료 확인을 다시 해야 한다. 저장 때는 허용된 사건·주장·자료 필드만 기존 인증/CSRF/소유권 API에 보낸다. 파일이 주장하는 계정/권한·검수·학습 승인과 정답/평가 참고표는 허용하지 않는다. 실제 판결문·개인정보 자료의 기존 승인·검수·격리 절차는 그대로다.

## 예시와 검증

화면에서 TXT·MD·JSON 예시를 내려받을 수 있다. 세 예시는 모두 AI가 작성한 합성 자료로 사람 검수·학습 승인·독립 최종셋이 아니다.

로컬 run `20261021T140757+0900-case-file-import-2c58e5`에 실제 명령·시각·종료코드/결과를 보존한다. frontend34 tests·타입/빌드 PASS, 세 형식과 기존12개 사건을 실제 파서로 변환한15건을 새 합성 API에 저장했다. 공개1/대기1 유지·모의 질문 완료·CSRF403/다른 소유자404 PASS다. 브라우저에서 실제 파일 선택·형식 오류·작성 중 입력 보존/복원·미리보기/명시적 저장·320/390/768/1280px 넘침 없음도 확인했다. 실제 모델 성능이나 운영 배포 근거가 아니다.

미리보기는 기존8132 주소·기존 합성 계정/사건 DB를 유지하고 프론트만 새 사본의 빌드를 제공한다. 실제8100/UID499·모델/학습·보호 검수 소스는 변경하지 않는다. 이번 작업의 백엔드 제품 소스 변경은 없다.
