# 운영자 화면

/admin(개요), /admin/logs(필터·페이지·상세·상관 ID), /admin/requests(HTTP), /admin/llm(실측 시도/지연/토큰), /admin/rag(현재 사건 keyword), /admin/mcp(실제 stdio 도구), /admin/errors(안전한 코드별 집계), /admin/system(현재 프로세스 범위).

동일 Vue 앱의 별도 운영 레이아웃이며 로그인은 사용자와 같은 이메일·비밀번호 화면이다. 서버가 계정의 admin 역할을 매번 검사한다. 일반 가입은 user이고 관리자가 되지 않는다. 별도 접근키·추가 관리자 로그인은 제거했다. [운영자 계정 생성·비밀번호 재설정](../AUTHENTICATION.md)을 따른다.

## 현재 적용 범위

localhost:8123의 새 합성 미리보기에 계정 방식을 적용했다. 기본 관리자/공유 암호를 만들지 않았다. 사용자 본인이 로컬 터미널에서 create-admin을 실행하고 같은 웹 로그인 화면으로 접속한다. 실제 UID499/8100은 예전 별도 코드 사본이므로 아직 변경하지 않았다. 계정 DB를 포함한 이전·백업/복구·코드 복귀는 후속 통합 검증이다. 과거 preview-user/preview-admin 키와 DB는 이전 검증 근거로만 보존한다.

## 지표 해석

실제 관측 시작 이후 retained 최대100,000개 안의 선택 기간만 집계한다. success는 HTTP400 미만/호출 SUCCESS, 오류는 HTTP400 이상/ERROR/INVALID다. 취소/차단은 성공에 넣지 않는다. 지연은 wall clock이며 MCP 시간은 직렬화 대기도 포함한다. HTTP는 헤더 응답까지로 SSE 스트림 수명과 다르다. 관리자/상태/정적 요청도 HTTP 분모에 포함한다.

미관측 토큰/지연은 null로 반환해 미측정으로 표시한다. fixture0토큰은 fixture에서 반환한0이며 실제 MLX 값으로 해석하지 않는다. CPU·메모리·과거 모델 변경 이력/현재 OS 격리는 미측정/미검증이다. 프롬프트·원문·원시 exception·평가 정답을 조회할 수 없고 임의 도구 실행도 없다.

MCP 연결 표시는 현재 앱이 초기화한 stdio 세션 객체의 존재이며 모델 ready와 독립적이다. 도구의 개별 성공·실패는 호출 기록을 확인한다. 취소는 오류 유형 집계에 넣지 않고 WARN 기록으로 남긴다.
