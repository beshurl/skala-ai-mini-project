# 사건 화면 QA·대화 통합

2026-10-21 사용자 요청으로 사건 목록·저장된 분석 탐색 수정과 사건별 증거 기반 대화를 통합했다. 사용 경로는 로그인 → 사건 기록 → 사건 선택 → **사건에 질문하기**다. 공개 증거를 읽고 질문·후속 질문을 보내며 인용 원문을 확인할 수 있다.

- 사건 목록과 검색을 작성 도구보다 먼저 표시하고 긴 제목·원문의 모바일 넘침을 보완했다.
- 선택한 분석의 `?job=`을 새로고침·뒤로가기·재로그인 후에도 유지한다. 같은 사건의 분석을 바꿀 때 읽던 위치를 유지한다.
- 현재 사건의 대화·인용·증거 버전·취소·저장 이력을 기존 단일 Worker에 연결했다. 질문 전송은 명시적으로 요청해야 하며 자동 모델 재시도는 없다.
- `unclassified` 기존 사건의 새 대화는 서버에서 거부한다. 소유권 확인을 자료 처리 승인으로 바꾸지 않는다.
- 질문 전송·새로고침·후속 질문 버튼은 공통 디자인 시스템의 `rc-button`을 사용한다.
