# ADR-003 — 기존 어댑터 보존과 출력 계약 평가

상태: 채택, 2026-10-20 KST.

상황: 원본15건 점수와 어댑터가 있고, 추가 사용자 로그가4B 명시/100회 학습 완료를 확인한다. 반면 세 템플릿 반복과 정확 프롬프트 중복이 발견되어 일반화 증거가 부족하다.

결정: 기존 파일을 백업/해시 보존하고 재학습하지 않는다. 설치된 CLI/signature와 오프라인4B revision을 확인해54건 Base/FT를 같은 조건으로 순차 실행한다. label/reason/evidence_ids 계약, 누락/중복/접근 불가 근거 검증, 고정3클래스 F1, 원시/복구 결과와 호출/토큰/지연/메모리를 함께 기록한다. 기존 test는 개발 노출셋으로 분류한다.

대안: 단순 label 추출만으로 성공 처리하는 방식, 좋은 사례만 재평가, 결과를 본 뒤 프롬프트/가중치 조정, 데이터 문제를 더 긴 학습으로 덮는 방식은 기각한다.

결과: 기존 FT는 합성 데모에서 사용할 수 있지만 실사용 승격은 보류한다. 새 독립 시나리오/문서/사건 계열 분할과 사람 검수 없이 학습 후보를 늘리지 않는다. 과거 revision/원시 손실을 새 검증 결과로 소급해서 채우지 않는다.
