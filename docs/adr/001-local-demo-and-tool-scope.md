# ADR-001 — 제한된 로컬 데모와 서버 발급 도구 권한

상태: 채택, 2026-10-20 KST.

상황: 기존 참고 프로젝트는 인시던트 대응 교육용이며 사용자별 사건·비공개 증거 경계가 없다. 실제 사용자 인증 제공자나 공개 운영 환경은 제공되지 않았다.

결정: loopback/trusted host/same-origin에서만 명시적으로 진입하는 로컬 데모를 구현한다. 무작위 cookie 세션으로 owner를 서버에서 정하고 쓰기는 CSRF를 요구한다. 공개 사건/작업/결과/SSE/비교 모두 동일 경계를 적용한다. MCP에는 짧은 HMAC case/version scope와 읽기 전용 DB를 부여한다. 모델은 자격정보를 보거나 권한을 선택하지 않는다.

대안: 사용자 요청 body의 owner 신뢰는 기각. 실제 OAuth/클라우드 인증은 현재 조건에서 검증할 수 없어 보류. 모델이 직접 파일/URL 도구를 고르는 범용 에이전트는 범위 초과이며 채택하지 않는다.

결과: 다중 로컬 세션 격리와 비공개 증거 방어를 테스트할 수 있다. 실제 조직 역할 체계, 인터넷 인증, OS 사용자 간 파일격리는 별도 검증 필요.
