# ADR-002 — 한 모델과 버전 고정 작업

상태: 채택, 2026-10-20 KST.

상황: M5 16GiB에서 모델을 요청마다/에이전트마다 로드하면 메모리 낭비가 크다. 증거 공개 중인 분석의 정합성이 필요하다.

결정: singleton MLX 모델, process lock, 생성 thread lock, 대기 큐8/worker1. 작업은 요청 시 공개 스냅샷과 model/version을 저장한다. 범용 재계획 대신 scope→검색→분석→검증의 LangGraph를 사용한다. 검색 결과에 포함된 공개 증거만 모델에 전달한다. 최종 DB transaction에서 취소와 최신 증거 버전을 다시 검사한다. 새 버전이면 STALE, 재시작 진행 작업은 실패로 종료한다.

대안: 결과 캐시·병렬 모델·무제한 재검토·자동 checkpoint resume는 필요성과 이점이 입증되지 않아 채택하지 않는다. JSON 복구는 코드펜스/완결 think 제거1회로 한정한다.

결과: 실행 예산을 설명할 수 있고 실패를 감추지 않는다. 자동 재개와 고동시성은 제공하지 않는다. 비교 결과는 같은 사건의 시간상 이전 분석만 허용한다.
